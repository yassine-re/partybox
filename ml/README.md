# Recommandation de missions (prévu)

Ce dossier accueillera plus tard le code Python d’entraînement et d’évaluation d’un modèle de recommandation. Aucun modèle, appel LLM, pipeline de données ou dépendance ML n’est implémenté pour le MVP.

Les missions actuelles viennent exclusivement du catalogue statique PostgreSQL. Définir d’abord les données utiles, leur durée de conservation et les critères de recommandation avant d’ajouter du code ici.
